Документация для библитеки matrix.h для работы с вещественныим матриами


В этой реализации матрицы хранятся в виде структуры matrix, где

	mtrx - двумерный массив для хранения значений матрицы;
	n, m - количество строк и столбцов матрицы, соответсвенно.


Функция init_mtrx служит для создания и инициализации матрицы с клавиатуры с заданными размерами.
	Возвращает:
		0  - Если матрица успешно была создана и инициализированна;
		-1 - Если при инициализации матрицы, в качестве значений были поданы неподходящие данные.

Функция outp_mtrx печатает на экран матрицу, указатель на которую будет находиться в параметрах функции.
	Возвращает:
		0  - Если печать прошла успешно;
		-2 - Если матрицы по данному адресу не сущестует.

Процедура del_mtrx удаляет матрицу, указанную в параметрах; очищает память, выделенную под эту матрицу.


Функция add_mtrx складывает две матрицы одинаковых размеров и 
		 записывает результат вместо матрицы, первой в списке параметров.
	Возвращает:
		0  - При успешном сложении;
		-1 - В случае, если матрицы разных размеров;
		-2 - В случае, если одна из матрицы не существует.

Функция mul_num_mtrx умножает матрицу на заданное вещественное число.
	Возвращает:
		0  - Если умножение совершенно успешно;
		-2 - Если матрицы по заданному адресу не существует.

Функция mul_mtrx перемножает друг с другом две заданные матрицы.
	Возвращает:
		NULL - Если 1) Матрицы не могут быть перемножены из-за несоответствия размеров;
			    2) Одной из матриц не существует.
		Новую матрицу, являющуюся произведением двух заданных в качестве параметров матриц.

Функиця det_mtrx находит определитель квадратной матрицы.
	Возвращает:
		0 - Если 1) Матрица не квадратная;
			 2) Матрица не существует;
		Вещественное число, являющееся определителем данной матрицы.
